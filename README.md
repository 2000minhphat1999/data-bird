# BirdCLEF 2026 Dataset

This repository hosts the birdclef-2026 training dataset (~12 GB) as GitHub Release assets.

## Download

Go to [Releases](https://github.com/2000minhphat1999/data-bird/releases) and download all `birdclef-2026.7z.*` parts.

## Extract

```bash
7z x birdclef-2026.7z.001
```
