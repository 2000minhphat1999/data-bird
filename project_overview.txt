1. BÀI TOÁN (Competition Overview)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━loa━━━━━━━━━━━━━━

Tên       : BirdCLEF+ 2026
Platform  : Kaggle
Task      : Multi-label sound event detection (SED) trên soundscape recordings
Input     : File âm thanh soundscape (OGG), chia chunk 5 giây
Output    : Xác suất xuất hiện của từng loài trong mỗi chunk 5s
Metric    : ROC-AUC (macro, bỏ qua classes không có positive trong batch)

Đặc điểm nổi bật so với BirdCLEF trước:
  - Mở rộng ngoài chim (Aves): thêm Amphibia, Insecta, Mammalia, Reptilia
  - Data từ iNaturalist (không phải Xeno-canto)
  - 234 loài thay vì ~180 như 2024/2025

4. PIPELINE KỸ THUẬT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

── 4.1 Audio Preprocessing ─────────────────────────────────────────────────────

  Sample rate  : 32,000 Hz
  Chunk length : 5 giây = 160,000 samples
  Pad strategy : tile (lặp lại) nếu clip ngắn hơn 5s
  Crop strategy: random crop trong training

── 4.2 Mel Spectrogram ─────────────────────────────────────────────────────────

  n_fft       : 1024
  hop_length  : 320    → ~100 frames/giây
  n_mels      : 128
  fmin        : 20 Hz
  fmax        : 16,000 Hz
  Output shape: (1, 128, 500)  — 1 channel, 128 mel bins, 500 time steps
  Backend     : librosa (ưu tiên) hoặc numpy fallback

── 4.3 Model Architecture ──────────────────────────────────────────────────────

  Backbone    : EfficientNet-B0 (timm)
  Input       : (B, 1, 128, 500)
  Feature dim : 1280 (sau GlobalAvgPool)
  Head        : Dropout(0.3) → Linear(1280→512) → ReLU → Dropout(0.15) → Linear(512→234)
  Output      : (B, 234)  raw logits
  Loss        : BCEWithLogitsLoss + pos_weight (class imbalance)
  Total params: 4.78M
  Model size  : ~19 MB (FP32)

── 4.4 Training Config ─────────────────────────────────────────────────────────

  Epochs        : 20 (early stopping patience=5)
  Batch size    : 16 (effective 32 với grad_accum=2)
  Optimizer     : AdamW (lr=1e-3, weight_decay=1e-4)
  Scheduler     : Cosine Annealing + 2 epoch warmup (min_lr=1e-6)
  AMP           : Mixed Precision FP16 (tiết kiệm ~50% VRAM)
  Grad clip     : 1.0
  Augmentation  : Mixup (alpha=0.5, p=0.5) + SpecAugment (time=20, freq=10)
  CV            : StratifiedKFold 5-fold theo primary_label

── 4.5 Inference ────────────────────────────────────────────────────────────────

  Input        : soundscape OGG file
  Chunking     : non-overlapping 5s windows
  TTA          : original + time-flip (average 2 predictions)
  Output       : submission.csv (row_id × 234 species probabilities)
  row_id format: {filename}_{end_second}
